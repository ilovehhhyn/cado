01 / PhilosophyKeep the reward honest.

A failed machine
isn’t a failed idea.

When a sandbox breaks, a GPU runs out of memory, or a grader never returns, a zero can look like feedback. The model learns from it anyway.

We think learning systems deserve better instruments. Ones that preserve what happened, distinguish failure from performance, and make uncertainty visible.

Cado starts there.

(01)

Observe before optimizing.

One typed outcome for every attempt. A record you can inspect before you trust the curve.

(02)

Keep causes separate.

Agent, grader, infrastructure, timeout. Different failures should lead to different decisions.

(03)

Make the work inspectable.

Open code, reproducible methods, and results with their limitations still attached.

02 / Why CadoThe expensive part is not knowing.

The model gets blamed.
The meter keeps running.

A timeout can look like a wrong answer. A broken verifier can look like a bad policy. By the time the reward curve tells you, you’ve already paid for the steps.

A higher score isn’t
the whole story.

The dataset is imbalanced: flagging every run as faulty beats every method on F1. Our detector falsely flags 2 of 11 normal runs under these labels.

What this benchmark does — and doesn’t — tell us +

This measures faults present from the first step, not faults that appear mid-run. Protocol A uses the paper’s labels. Protocol B treats 224 un-injected controls as normal; tplane scores 85.58 hard F1 with 4 / 235 false alarms.

Results use outer five-fold cross-validation on 779 runs. Thresholds are selected within each training fold, but prior feature exploration used the same outer folds and introduces selection bias. This is early evidence, not a production reliability claim.

02 / example.py
from pathlib import Path
import tplane

run = tplane.Run(
    run_id="first-run",
    store=tplane.FileRecordStore(Path("runs/first")),
    # Demo only: resource sampling disabled.
    read_host=lambda: 0,
    read_gpu=lambda: (),
    gpu_total_bytes=(),
)

def rollout(unit):
    # Replace with your generation and grading.
    with unit.stage(tplane.Stage.ROLLOUT):
        unit.tokens(tokens_in=12, tokens_out=48)
    with unit.stage(tplane.Stage.GRADE):
        unit.reward(1.0)

result = run.attempt(
    "trajectory-001",
    kind=tplane.UnitKind.TRAJECTORY,
    body=rollout,
)
print(result.record.decision.action)
03 / Terminal
python example.py
tp show runs/first

Use a fresh run directory when repeating this example.
Already-recorded attempts are intentionally never overwritten.
